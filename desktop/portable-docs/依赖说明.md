# 源鉴桌面版依赖说明

## 随发行目录提供

生产前端、FastAPI后端、pywebview及从选定产品环境复制的Windows x64 Python运行库。实际版本见 `app/DEPENDENCY_VERSIONS.json`（非便携布局位于程序根目录）。窗口Python依赖固定在源码 `desktop/window-requirements.txt`，构建工具另列在 `build-tools-requirements.txt`。

保留Python和各第三方库的LICENSE、COPYING、NOTICE及dist-info/licenses等许可文件；使用和再分发遵循各组件许可。运行库依赖不是安装器，不会自动安装系统组件或模型。

## 外部资源

- **完整BGE-M3模型**：[BAAI模型仓库](https://huggingface.co/BAAI/bge-m3)。目录应含模型配置、分词器、Pooling配置及权重；缓存链接必须同时保留其实际目标文件，不能只复制快照空壳。
- **完整Git for Windows**：[Git官方下载](https://git-scm.com/install/windows)。选择完整安装/Portable目录或实际git.exe，不能只复制一个可执行文件。
- **Microsoft Edge WebView2 Runtime**：[微软官方页面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。窗口使用Edge Chromium后端，普通Edge浏览器不能代替运行库；缺失时不会退回旧IE后端。
- **.NET Framework 4.6.2或更高版本**：[微软安装说明](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-and-server)。保留Windows已有兼容版本，无需为本产品降级或安装.NET SDK。
- **模型运行资源与驱动**：GPU驱动须与实际发行Torch兼容；默认device=auto、batch_size=1、max_length=8192。CPU和其他GPU的内存、速度与兼容性需要单独验证。

打开窗口和设置不需要BGE、Git或API；进入工作台前宿主仍会检查模型/Git并准备模型。首次导入不调用生成API；RAG/Agent问答需要能连接服务商的有效配置。

## 数据与排错

`user-data/desktop-settings.json`保存个人设置，API Key使用当前Windows用户DPAPI加密，不以明文保存或回显。配置文件优先于发行默认设置。软件不读取开发项目真实.env；不要把自己的user-data发给他人。

缺资源时在设置选择完整目录后保存。窗口无法打开时先完整解压，再检查系统依赖并使用排错启动入口。日志位于当前数据目录logs；反馈时排除密钥、历史问答及私人数据库。

历史本机记录验证过窗口恢复、真实BGE导入、问答引用/全文、历史重开及退出。当前源码整合只做离线测试和两种前端构建，不重建完整运行库，不新增模型/Provider调用。换机、干净系统、其他GPU/CPU与安装器仍待验证。
