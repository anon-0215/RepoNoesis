# 源鉴便携试用操作卡

完整解压后再运行，保留整个 app 文件夹。API Key 由使用者自行填写。

1. 准备完整 BGE-M3 权重、Git for Windows、WebView2 Runtime 和 .NET Framework，详见《依赖说明.md》。包内运行库无需另外安装 Python、Conda 或 Node.js。
2. 双击 `源鉴.vbs`。窗口未打开时，用 `排错启动.cmd` 查看错误。缺模型/Git时可先进入设置。
3. 在窗口设置选择 BGE 完整权重目录和 Git 安装目录或 git.exe；生成问答另需 API 地址、模型和 Key。保存不会自动发送生成请求。Key 留空保留，显式勾选清除后保存才删除；密钥不回显。
4. 在“项目管理”导入已有 Python Git 仓库或公开 HTTPS Git。首次导入需要模型、Git、足够内存/磁盘，远程导入另需网络；不需要生成 API。分析只静态读取，不安装或运行目标仓库的代码。
5. 索引完成后可阅读源码、定位报错和对照用例；RAG/Agent生成问答需要有效 API，可产生服务商费用。引用可打开片段和完整源码。
6. 关闭窗口会结束本次后台。`user-data`首次运行时在app旁创建，存放设置、数据库、缓存、日志、仓库副本及窗口状态。设置可打开该目录。移动前关闭程序，移动整个文件夹；不要分发自己的user-data。更换Windows用户需重新填写Key。

## 检索增强开关

便携发行配置默认同时启用HyDE和单轮列表重排，只用于每题首次检索，Agent后续补搜不重复。共享最多15秒，计入原问答时限；失败会回退，执行摘要保存实际状态。

关闭窗口后编辑 `app/desktop-config.json` 中 `hyde_enabled`、`rerank_enabled`；若 `user-data/desktop-settings.json` 已有同名字段，以个人设置值为准，应编辑实际生效文件。`false`关闭，`true`启用；两者独立。其他字段尤其 `api_key_dpapi` 保持原样。该配置不会改变普通网页启动的默认设置。

当前是Windows x64试用源码/便携路线；换机、其他硬件及安装器尚未完成验证。不要把本机历史成功记录当作新机器已通过。
